# My-Portfolio

A responsive frontend developer portfolio built with React, Vite, and Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; run ESLint with `npm run lint`.

## Customize

Edit the four starter project entries in `src/components/Projects.jsx` to add your actual project names, descriptions, images, and links. Contact details are in `src/components/Contact.jsx`.

The page is split into reusable components in `src/components/`: header, hero, about, projects, contact, and footer.
